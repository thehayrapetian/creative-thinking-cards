# Existential Crisis Deck

Fifty-two prompts for a looser mind. Shuffle, draw a card, answer honestly, and keep your answers in a private journal that stays in your browser.

A static, single-page web app by [gevooorg](https://gevooorg.com). No build step: `index.html` plus a few icons. Works offline after the first visit.

Keyboard: Space / → draw or next card · ← previous direction throw · W write · S shuffle · J journal · Esc close.
